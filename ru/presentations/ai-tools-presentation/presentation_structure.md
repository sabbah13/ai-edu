## Interactive Elements
- Mini JS demos for MCP protocol examples

- Code examples with syntax highlighting
- iFrame embeds for live tool demonstrations

## Visual Design Guidelines
- Black background theme
- Transparent PNG logos for contrast
- Minimal text per slide (max 5-7 bullet points)
- High contrast white/yellow text
- Company logos prominently displayed
- Code snippets with proper syntax highlighting
- Interactive elements with hover effects

## Technical Requirements
- Optimized for macOS Chrome browser
- Responsive design for presentation screen
- Automated navigation testing
- Screenshot validation for all slides
- Performance optimization for smooth transitions
